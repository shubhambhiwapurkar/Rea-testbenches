# SUMMIT

**A realistic mountaineering expedition game built in Unreal Engine 5.** It uses real mountains at real scale. Climbers move from base camp through the high camps to the summit, carrying loads and keeping their balance the way you do in Death Stranding, while the game simulates altitude physiology, cold, weather, avalanches and rope physics from published science.

![Everest, built from Copernicus 30 m elevation data by Tools/terrain](Docs/images/everest_hillshade.png)

*The real 20 km × 20 km Everest massif (Khumbu Icefall, Western Cwm, South Col, Lhotse) as a 4033² Unreal Engine Landscape heightmap with procedural sub-30 m detail, generated by `Tools/terrain`. The summit is clamped to the surveyed 8848.86 m.*

> Status: **Phase 0: foundations.** The simulation core, data and terrain pipeline are developed and tested here. The UE5 project opens on a workstation (see the [Roadmap](Docs/Roadmap.md)).

## Quick start (no Unreal needed)

```bash
cmake -S . -B build && cmake --build build -j
ctest --test-dir build --output-on-failure
./build/summit_sim_cli everest                       # South Col summit push on bottled O2 (~7 h up)
./build/summit_sim_cli windows --seed 7              # find calm summit windows this season
./build/summit_sim_cli everest --no-o2 --elite --seed 7 --day 149   # no O2, inside a window
./build/summit_sim_cli everest --no-o2               # no O2 into 25 m/s jet-stream winds: don't
./build/summit_sim_cli trek --fast                   # skip acclimatization days and see what happens
./build/summit_sim_cli forecast --day 138            # 7-day summit forecast with confidence

python3 Tools/data/validate_data.py
pip install -r Tools/terrain/requirements.txt
cd Tools/terrain && python3 summit_terrain.py fetch --peak-id everest --extent-km 20
python3 summit_terrain.py build --peak-id everest --extent-km 20 --ue-size 4033 --detail --fit-landmarks
```

## Simulation calibration at a glance

| Scenario (headless CLI) | Result | Reality |
|---|---|---|
| Summit push with 3 L/min O₂ | South Col → summit 7.2 h; round trip 11-12 h | Leave ~22:00, summit ~05:00-06:00 |
| Elite climber, no O₂, calm window | Summit in ~12.5 h, home safe | No-O₂ ascents usually 10-15 h (Messner and Habeler 1978: ~8 h) |
| Strong climber, no O₂ | Turns around near 8,700 m | The most common real outcome |
| No O₂ in 25 m/s jet-stream wind | Hypothermia, rescue needed | Why expeditions wait for windows |
| Standard 10-day Khumbu trek | AMS score ≤ 1.6 | WMS-compliant itineraries rarely produce AMS |
| 4-day rush to EBC | AMS 3.4-3.6 | Classic fast-ascent AMS |

Full calibration targets and sources: [`Docs/TechnicalDesign.md`](Docs/TechnicalDesign.md#3-realism-references-calibration-targets-enforced-by-unit-tests).
